🖥️ Priority vs SRTF Scheduling Project

📌 Overview
Java-based OS simulation project
Compares Priority Scheduling vs SRTF algorithms

🎯 Objective
Study CPU scheduling behavior under different policies
Analyze fairness, efficiency, and starvation risk

⚙️ Features
Process scheduling with Arrival, Burst, and Priority
Supports preemptive SRTF and Priority scheduling
Calculates performance metrics (WT, TAT, CT)

📊 Goal
Understand impact of scheduling strategy on system performance
