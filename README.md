#  Priority vs SRTF Scheduling Project

---

##  Overview
This project is a **Java-based Operating Systems simulation project** that compares two CPU scheduling algorithms:

- Priority Scheduling  
- Shortest Remaining Time First (SRTF)

It demonstrates how different scheduling strategies affect process execution behavior in an operating system.

---

##  Objectives
- Study CPU scheduling behavior under different policies  
- Analyze fairness, efficiency, and starvation risk  
- Compare preemptive scheduling algorithms  
- Understand real-world OS scheduling decisions  

---

##  Features
- 🔹 Process scheduling with Arrival Time, Burst Time, and Priority  
- 🔹 Support for **Preemptive SRTF Scheduling**  
- 🔹 Support for **Preemptive Priority Scheduling**  
- 🔹 Calculation of performance metrics:
  - Waiting Time (WT)
  - Turnaround Time (TAT)
  - Completion Time (CT)

---

##  Goal
Understand the impact of scheduling strategies on overall system performance, efficiency, and process fairness.
